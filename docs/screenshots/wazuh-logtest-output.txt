=== Résultat ===

Les 3 cas correspondent exactement au tableau de correspondance severity -> level
documenté dans docs/wazuh.md :
  severity=high     -> rule 110012 -> level 10
  severity=critical -> rule 110013 -> level 12
  status=PASS       -> rule 110001 -> level 3

Bug corrigé au passage : le champ "status" est un nom réservé (statique) dans le
moteur de règles Wazuh (conflit avec le champ status natif des événements FIM).
<field name="status"> faisait échouer le chargement de la règle avec l'erreur
"Field 'status' is static." — corrigé en utilisant la balise dédiée <status>
(voir wazuh/manager/local_rules.xml et docs/wazuh.md).
